# 🚀 FUTURE_FS_02 – Mini CRM (Client Lead Management System)

## 📌 Overview

This project is a **Mini CRM (Customer Relationship Management) system** developed as part of the Full Stack Web Development Internship.

It allows users to manage client leads efficiently by adding, viewing, updating, and deleting lead information. The application demonstrates full-stack development with backend integration and database handling.

## ✨ Features

* ➕ Add new leads (Name, Email, Source, Notes)
* 📋 View all leads in a structured list
* 🔄 Update lead status (New / Contacted / Converted)
* ❌ Delete leads
* 💾 Persistent data storage using SQLite
* 🌐 Live backend deployment

## ⚙️ Installation & Setup (Local)

### 1. Clone the repository

```id="gpt6mz"
git clone https://github.com/KrithiP06/FUTURE_FS_02.git
```

### 2. Navigate to project folder

```id="u3fr9e"
cd FUTURE_FS_02
```

### 3. Install dependencies

```id="9x6hbd"
npm install
```

### 4. Start the server

```id="kjq8m1"
node server/server.js
```

### 5. Open frontend

Open:

```id="f8q0la"
client/index.html
```

## 🔌 API Endpoints

| Method | Endpoint       | Description        |
| ------ | -------------- | ------------------ |
| GET    | /api/leads     | Fetch all leads    |
| POST   | /api/leads     | Add new lead       |
| PUT    | /api/leads/:id | Update lead status |
| DELETE | /api/leads/:id | Delete lead        |
